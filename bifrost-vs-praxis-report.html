# Funkcionalita Priorita Praxis status Detail
1 Unified API pro 23+ providerů Kritická ● Částečně Praxis má translation jen pro OpenAI + Anthropic. Chybí Bedrock, Vertex AI, Azure OpenAI, Cohere, Mistral, Groq, Cerebras, Ollama aj.
2 Automatický failover mezi providery Kritická ◈ Roadmap Ordered failover chains s automatickým API překladem. Core "zero downtime" feature Bifrostu.
3 Semantic caching Kritická ◈ Roadmap Prompt deduplikace přes vector similarity. Bifrost má built-in plugin s vector store backendem.
4 Budget management Vysoká ✕ Ne Hierarchické limity: virtual keys → teams → customers. Praxis má jen informativní token headery.
5 Cost attribution Vysoká ◈ Roadmap Token counting per user / session / model / endpoint.
6 Web UI Střední ✕ Ne Vizuální konfigurace, real-time monitoring, analytics. Řešitelné externím dashboardem.
7 User provisioning (OIDC) Střední ✕ Ne OAuth 2.0 / OIDC login, directory sync. Praxis má Basic Auth + mTLS.
8 Virtual keys Střední ✕ Ne Abstrakce nad reálnými API klíči pro governance a tracking.
9 SDK drop-in replacement Střední ● Částečně Bifrost: OpenAI, Anthropic, Google GenAI, LangChain, LiteLLM. Praxis: jen OpenAI + Anthropic.
10 Multimodal (text, image, audio) Střední ● Částečně Praxis projde multimodal jako proxy passthrough, ale nemá dedikovanou logiku.
11 Cluster mode Střední ✕ Ne Multi-node horizontal scaling (Bifrost enterprise).
12 Plugin marketplace Střední ● Částečně Bifrost: 7 runtime pluginů. Praxis: compile-time Rust filtry (jiný model).
13 NPX one-click install Nízká ✕ Ne Rust binary vyžaduje build nebo pre-built release.
14 Helm charts Nízká ✕ Ne Kubernetes deployment. Lze snadno vytvořit.
15 Terraform moduly Nízká ✕ Ne IaC deployment šablony. Lze vytvořit.

Kde Praxis Bifrost překonává

15 výhod

TCP/L4 Proxying

Proxy libovolného TCP protokolu, nejen HTTP. Bifrost je čistě HTTP.

Circuit Breaker

Per-cluster s half-open probe window a gradual recovery. Bifrost jen failover.

A2A Protocol

First-class Agent-to-Agent podpora s task-ownership routing. Bifrost nemá.

OpenAI Responses API

Kompletní /v1/responses implementace s conversation store (SQLite/PG).

StreamBuffer

Unikátní peek-then-stream: inspekce prvních N bytů bez plného bufferingu.

Bidirectional API Translation

Plná obousměrná Anthropic ↔ OpenAI transformace, ne jen passthrough.

Response Compression

gzip, Brotli, Zstandard s content-type filtering a min size thresholds.

Kompletní Security Stack

CORS, CSRF, IP ACL, mTLS, Basic Auth, SSRF protection, no-unsafe-code policy.

Path/URL Rewriting

Regex-based, prefix strip/add, query string manipulation.

Compile-time Extensions

Rust trait-based s auto-discovery. Zero runtime overhead.

Atomic Hot-Reload

In-flight requests dokončí na staré konfiguraci, nová se swapne atomicky.

JSON-RPC 2.0 Foundation

Generická podpora pro agentic protokoly na úrovni envelope parsingu.

gRPC Detection

Automatická detekce gRPC/gRPC-Web content types.

Response Persistence

Nativní SQLite/PostgreSQL store pro Responses API konverzace.

No-unsafe-code Policy

unsafe_code = "deny" v celém workspace. Rustls bez OpenSSL/C FFI.
